Habit Tracker

Overview

A local Spring Boot application designed to track daily habits and dynamically calculate streaks using event-based completion data.

Problem & Motivation

I wanted a lightweight habit trackere that runs locally, persists data reliably, and avoids derived-state bugs by calculating streaks dynamically.

Key Features

  • CRUD management of habits
  • Daily completion tracking
  • Dynamically calculated streaks
  • SQLite Persistence
  • Service and controller unit testing

Tech Stack

Java 17 Spring Boot Spring Data JPA SQLite Thymeleaf JUnit / Mockito

What I learned

  • Designing event-based domain models
  • Dynamic streak calculations
  • Layered testing strategies
  • Packaging Spring Boot apps as standalone JARs
